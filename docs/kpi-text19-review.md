# ตรวจ 19 ตัวชี้วัดชนิด "ข้อความ" — ทำให้เทียบรายเดือนได้ (Phase 2)

> สร้าง **6 ส.ค. 2569** · ประกบ 3 ทาง: สถานะจริงใน DB + ไฟล์ `ตัวชี้วัดตรวจราชการ 69 รอบ 1.xlsx` + ข้อเสนอของ dev  
> **dev จะยังไม่แก้อะไรจนกว่าจะติ๊กยืนยัน** (กฎ CLAUDE.md ข้อ 5 — ห้ามเดาเป้า)
> อัปเดต **11 ส.ค.**: ✅ **ข้อ 21 เสร็จแล้ว** — เจ้าของระบบหาเอกสารทางการมาเอง เป้า/ทิศทาง/หน่วยจริงต่างจากที่เสนอในนี้ทั้งหมด (ดูการ์ดข้อ 21 ด้านล่าง) **เหลือ 18 ตัวที่ยังรอตอบ**

## ทำไมต้องทำ

ตัวชี้วัดชนิด **"ข้อความ"** เก็บผลงานเป็นประโยค (เช่น "อยู่ระหว่างดำเนินการ") → **ไม่มีตัวเลขให้เทียบเดือนต่อเดือน**
ไม่มีกราฟ ไม่มีแนวโน้ม ไม่ตัดสินผ่าน/ไม่ผ่าน · ถ้าเปลี่ยนเป็น **"ตัวเลข"** หรือ **"ระดับ"** ได้ จะดูย้อนหลังและเทียบไตรมาสได้ทันที

## 🔑 ข้อค้นพบสำคัญ — อ่านก่อน

ไล่ดูครบทั้ง 19 ตัวแล้วพบว่า **ไม่มีตัวไหนเลยที่ไฟล์ให้ "เป้าระดับ รพ." เป็นตัวเลข** —
ทุกตัวที่มีตัวเลข เป็นตัวเลขของ**ระดับเขต/จังหวัด** ส่วนช่องเป้า รพ. ถูกเว้นว่างหรือขีด `-` ไว้

**แปลว่าทุกตัวในกอง A ต้องให้เจ้าของระบบเคาะก่อนว่า "รพ. ใช้เป้าเดียวกับเขต/จังหวัดได้ไหม"** — dev ตัดสินใจแทนไม่ได้

## วิธีใช้เอกสารนี้

ไล่ทีละการ์ด ตอบแค่ข้อเดียวต่อ 1 ตัวชี้วัด:

| ตอบว่า | แปลว่า |
|---|---|
| ✅ **เอาตามที่เสนอ** | dev แก้ให้ตามข้อเสนอเลย |
| ✏️ **แก้เป็น...** | บอกเป้า/ลำดับขั้นที่ถูก แล้ว dev แก้ตามนั้น |
| ⏭️ **ข้ามไปก่อน** | คงเป็นข้อความเหมือนเดิม ไม่ต้องทำอะไร |

### ✅ ข้อ 21 — อัตราการฆ่าตัวตายสำเร็จ (crude suicide rate) — เสร็จแล้ว 11 ส.ค.

`kpi-1785354100574` · รายละเอียดเต็ม: `kpi-keyin-plan.md` §Phase 3

**ไม่ได้ใช้ข้อเสนอเดิมในการ์ดนี้เลย** — ตอนแรก dev เสนอเป้า=65 (ยกจากเป้าเขตในไฟล์ตรวจราชการ) แต่เจ้าของระบบหา **เอกสารทางการ** มาเอง (`inspection.moph.go.th/uploads/kpi_files/kpi_22.pdf`) แล้วพบว่า:
- ไฟล์ตรวจราชการดงเจริญเขียน**ผิดตัวชี้วัด** — ปนตัวย่อย ("ร้อยละเข้าถึงบริการ" เป้า 65) เข้ากับตัวหลัก (crude suicide rate เป้า 7.8) ในชื่อเดียวกัน
- เจ้าของระบบเลือกใช้ **ตัวหลัก** → ชื่อใหม่ "อัตราการฆ่าตัวตายสำเร็จ (crude suicide rate)" · เป้า **7.8 ต่อแสนประชากร** (ปีงบ 69 จากเอกสาร) · ทิศทาง **ยิ่งน้อยยิ่งดี**
- หน่วย "ต่อแสนประชากร" ไม่ใช่ % ธรรมดา → ต้องเพิ่ม `rate_per` ให้ engine รองรับ (งานนี้พ่วงมาด้วย เผื่อใช้กับ #12 มารดาตายที่หน่วยเดียวกัน)

**บทเรียน:** เป้าที่ "ยกจากเขต/จังหวัด" แบบเสนอในเอกสารนี้เป็นแค่ทางเลือกสำรองเมื่อไม่มีข้อมูลอื่น — **ถ้าหาเอกสารนิยามทางการของ MOPH เจอ (`inspection.moph.go.th/uploads/kpi_files/kpi_XX.pdf`) ให้ยึดอันนั้นก่อนเสมอ** ตัวอื่นในกอง A/B ที่เหลือถ้ามีลิงก์แบบนี้ส่งมาได้ จะแม่นกว่าเดาจากไฟล์ Excel มาก
