## เริ่ม / หยุด ระบบ

| คำสั่ง | ความหมาย |
|---|---|
| `npm run dev` | เริ่ม Development mode (มี hot-reload) |
| `npm run build` | Build สำหรับ Production |
| `npm run start` | เริ่ม Production mode |
| `Ctrl + C` | หยุดเซิร์ฟเวอร์ |

```bash
# เริ่มบน port อื่น
PORT=3055 npm run start          # Linux/Mac
set PORT=3055 && npm run start   # Windows CMD
$env:PORT=3055; npm run start    # Windows PowerShell
```

## PM2 (รัน Background — Windows/Linux)

```bash
npm install -g pm2               # ติดตั้ง PM2 ครั้งแรก

npm run build                    # build ก่อนเสมอ
pm2 start "npm run start" --name dhdc-kpi   # เริ่ม
pm2 start "npm run start" --name dhdc-kpi -- -p 3055  # เริ่มบน port 3055

pm2 list                         # ดูรายการ process
pm2 status                       # ดูสถานะ
pm2 logs dhdc-kpi                # ดู log
pm2 logs dhdc-kpi --lines 50     # ดู log 50 บรรทัดล่าสุด
pm2 restart dhdc-kpi             # restart
pm2 stop dhdc-kpi                # หยุด
pm2 delete dhdc-kpi              # ลบออกจาก PM2
pm2 save                         # บันทึก config (รันหลัง startup)
pm2 startup                      # ให้ PM2 เริ่มเองตอน boot
```

## Systemd (Linux เท่านั้น)

```bash
sudo systemctl start dhdc-kpi    # เริ่ม service
sudo systemctl stop dhdc-kpi     # หยุด service
sudo systemctl restart dhdc-kpi  # restart
sudo systemctl status dhdc-kpi   # ดูสถานะ
sudo systemctl enable dhdc-kpi   # เริ่มอัตโนมัติตอน boot
sudo systemctl disable dhdc-kpi  # ยกเลิกเริ่มอัตโนมัติ

sudo journalctl -u dhdc-kpi -f           # ดู log แบบ real-time
sudo journalctl -u dhdc-kpi -n 100       # ดู log 100 บรรทัดล่าสุด
sudo journalctl -u dhdc-kpi --since today  # log วันนี้
```

## Port & Process

**Windows:**
```cmd
netstat -ano | findstr :3000        # หา process ที่ใช้ port 3000
taskkill /PID <PID> /F              # ปิด process
tasklist | findstr node             # หา node process ทั้งหมด
```

**Linux:**
```bash
sudo lsof -i :3000                  # หา process ที่ใช้ port 3000
sudo kill -9 <PID>                  # ปิด process
pkill -f "next start"               # ปิด next.js ทั้งหมด
ps aux | grep node                  # ดู node process ทั้งหมด
```

## ไฟล์ Config สำคัญ

| ไฟล์ | หน้าที่ |
|---|---|
| `lib/db.ts` | host, user, password, database ของ MariaDB |
| `.env.local` | MOPH_CRON, PORT, MOPH_FETCH_PROVINCE, ฯลฯ |
| `next.config.mjs` | instrumentationHook, config Next.js |
| `lib/initialData.ts` | ข้อมูล seed เริ่มต้น (users, KPIs, monthly) |
| `lib/scheduler.ts` | ตาราง cron + timezone |
